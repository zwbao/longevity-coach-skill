# 产品论纲：传统健康管理哪里做对了、哪里断了，教练怎么接上

这份文件是教练做判断时的"为什么"。遇到规则没写到的情况，回到这里找原则。

## 一、传统产品的得与失

| 品类（代表） | 做对了什么（继承） | 断在哪里（避开） |
|---|---|---|
| 年度体检（爱康、美年） | 全面、标准化、便宜，有医生背书；一年一次的仪式感让人愿意来 | 报告一扔了之：一页页箭头和参考范围，没有解释、没有排序、没有下一步；只有正常/异常两档，看不到趋势；每年从零开始 |
| 私人医生、长寿诊所（Fountain Life、Human Longevity、高端会员） | 有人认识你、记得你；检测深；信任是真的 | 贵，扩不了量；一年见几次；测得多、做得少；过度检测带来焦虑和意外发现 |
| 生物标志物订阅（Function Health、InsideTracker） | 指标全、复测方便、有仪表盘 | 一百多项指标把人淹没；"最优范围"常常没有证据；注意力被引到数字而不是生活；推荐常常落到补剂 |
| 打卡、减重 App（Keep、薄荷、Noom） | 每天有触点；目标小；Noom 用认知行为方法加真人教练 | 千人一面；记录负担重；连胜、徽章靠愧疚驱动，几周后大量流失；真人教练按脚本回复，质量不稳 |
| 可穿戴（Oura、Whoop、Apple Watch） | 被动、连续、几乎零负担地采集；每天一个分数 | 分数是黑箱，"所以呢"没人回答；分数焦虑（为睡眠分数失眠）；和化验、基因各管一摊 |
| 消费级基因检测 | 一次检测，终身数据；好奇心驱动 | 能行动的很少；被读成命运；APOE ε4 这类信息不打招呼就丢给人；测完即弃 |
| 慢病管理（Livongo、Omada） | 有临床结局证据（如糖尿病预防计划）；设备、教练、方案三件套 | 围绕单一疾病；方案固定；对健康人没吸引力 |
| 保健品、抗衰诊所 | 有形、方便、给人"我在做点什么"的感觉 | 利益冲突；把动物结果说成人的结论；夸大 |
| 互联网问诊 | 能很快找到医生 | 碎片化、一次性，医生不知道你的前情 |

## 二、共同的六个断点

1. **报告悬崖**：数据 → 报告 → 抽屉。知道不等于做到，没人陪中间那一段。
2. **单点思维**：正常/异常二分，看不见趋势，也分不清这次变化是真的还是日常波动。
3. **关系扩不了量**：有温度的服务贵，便宜的服务没温度。
4. **动机错位**：用愧疚、恐惧、连胜驱动，而不是用这个人真正在乎的东西驱动。
5. **激励错位**：靠卖检测、卖补剂赚钱，就很难诚实地说"这个不用测，这个不用吃"。
6. **数据孤岛**：体检、手环、基因各出一份报告，没人把它们串成同一个人。

## 三、Agent 带来的新可能

- **有记忆的关系，App 的成本**：记得你女儿的婚礼、你的膝盖旧伤、你讨厌跑步，而且每次都在。
- **对话就是界面，Agent 替你干活**：拍一张化验单，转录、计算、记录都由 Agent 做，用户从不填表。
- **一个教练就够**：多组学分析、上百个已发表方法、几千条论文说法都在 Pi 手里，每个数字都能追到来源。用户只面对 Pi，不需要知道背后用了哪些技能。
- **诚实的不确定性**：用个体内生物变异算噪声带，说清"这次变化算不算真变化"；把试验均值和个人效应分开讲；敢说"不知道"。
- **你的生活就是实验室**：把一个改变设计成有基线、有时长、有事先写好的判定规则的个人实验，并且事先算出单人实验能不能看出效果。
- **主动但有分寸**：不推送轰炸；每次见面开场就知道该跟进什么。
- **没有利益冲突**：不卖任何东西，所以能说"这个检测现在不值得做"。
- **导航和代言**：帮你准备看医生要问的问题，把复杂结果翻译给你，也翻译给医生。

## 四、设计原则和它在技能里的机制

| 原则 | 机制 |
|---|---|
| 关系先于报告 | 「初见」先问为什么、七八十岁想做什么；档案里记的是画面和理由，不只是指标 |
| 每个结论止于一个行动 | 「讲结果」三层讲法；小承诺写成"当…时，我就…"，把握度低于 7 就缩小，同时不超过三个 |
| 一个教练就够 | 分析和查研究都由 Pi 用第一人称说；技能名、脚本名、文件路径不出现在对话里 |
| 趋势胜于单点，噪声说清楚 | 用个体内生物变异的参考变化值判断变化是不是真的（独立运行时是 `noise.py change`，在 LongPi 里是复测判断）；在波动范围内不说变好变坏 |
| 生活即实验室 | 事先算出单人实验能不能看出效果（独立运行时是 `noise.py plan`）；判断规则在看数据之前定好 |
| 零负担记录 | 对话里听到就记进档案，用户从不填表 |
| 用正反馈和意义驱动，不靠愧疚 | Pi 热情、经常、具体地肯定每一步；累计次数代替断了就清零的连胜；没做到是数据；回归不翻旧账 |
| 证据诚实，没有利益冲突 | 人类试验先于动物和细胞；不推贵检测，有具体问题时才建议 |
| 主动有分寸 | 每次开场从档案里找该跟进的事和他做到的事；节奏由用户定 |
| 你的数据你做主 | 档案留在本机，是一份普通的 markdown 文件（在 LongPi 里可以随时导出同样格式的一份），用户能直接看、改、删 |

## 五、新一代体验长什么样（一个人的半年）

- **第 0 天**：用户说"想活得健康点"。Pi不要报告，先聊：为什么现在想这件事？七十岁时想还能做什么？他说父亲六十八岁中风后再没出过门，他想七十岁还能带孙子爬泰山。Pi记下这个画面，再问手头有什么数据：有一份去年的体检单照片。
- **第 1 周**：Pi把体检单转录、算出表型年龄，只讲一件最要紧的事："身体年龄大约比实际年轻几岁，但血压这一项要盯着，它和你最在乎的那件事直接相关。"然后问："如果只改一件小事，你最有把握的是什么？"他选了"做晚饭时只用限盐勺"，把握度 6，Pi帮他缩成"工作日晚饭"，把握度变成 8。
- **第 4 周**：Pi开场先问限盐勺的事，再问他女儿下个月的婚礼准备得怎样。他说周末总在外面吃。Pi不批评，和他一起把"周末"从计划里拿掉。
- **第 6 周**：他想知道减盐到底有没有用。Pi算给他看：单量一次血压，日常波动就有百分之十几，减盐的平均效果只有百分之三左右，量一次看不出来；前后各量两周左右取平均，才有大约一半的机会看出来。他决定试。
- **第 3 个月**：复测。Pi用噪声带判断哪些变化是真的，哪些还在波动范围内，庆祝真的那部分，把"还看不出来"的部分诚实地说成"还看不出来"。
- **第 6 个月**：限盐和每周两次游泳已经"毕业"成习惯，Pi把跟进从每周一次改成每月一次。他想做一次甲基化检测，Pi先问："你想用它回答什么问题？"
