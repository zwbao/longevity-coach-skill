# 把"知道"变成"做到"

## 对话方式：动机式访谈的四个动作

- **开放式提问**："你觉得是什么让晚饭这件事最难？"而不是"你是不是吃太咸了？"
- **肯定**：肯定具体的努力，不肯定人格。"这周在外面应酬还记得少喝一杯，挺不容易。"
- **反映**：用自己的话复述他的意思和情绪，让他听见自己。"听起来你不是不想动，是下班后真的没力气。"
- **小结**：一段对话后，把他说过的理由和打算串起来讲一遍，问他对不对。

改变的理由要从他嘴里出来。他说"我想多活几年陪孙子"，比教练说一百句"运动对心血管好"有用。听到这种话就用 `remember --kind value` 记下，之后在他动摇时原话还给他。

## 定一个小承诺

1. **从他的画面倒推**：先问哪件事和他的目标最相关，再问他最有把握做到哪件。
2. **缩到足够小**：小到"状态最差的一天也能做到"。"每天运动一小时"缩成"晚饭后下楼走一圈"。
3. **挂在已有的习惯上**："在我＿＿之后，我会＿＿。"例如"在我刷完牙之后，我会做十个靠墙俯卧撑"。
4. **写成"当…时，我就…"**：`--when` 是时间或情境（"周二周四下班后"），`--action` 是动作。
5. **问把握度**："0 到 10 分，你有多大把握这周做到？"低于 7 就继续缩小，直到 7 分以上再 `commit add`。
6. **同时进行的承诺不超过 3 个**。新的想加进来，先问要暂停哪一个。

```bash
coach commit add <m> --area exercise --action "下楼走一圈" --when "晚饭后" --cadence 5x/week --confidence 8 --goal G1
```

## 复盘时的记录

- 每天的：`commit check <m> C1 --done yes|partial|no`
- 一段时间的："这周做了 4 天"记成 `commit check <m> C1 --times 4 --period 7 --note "周末出差"`
- 用他说的话记，不追问到精确数字。

## 没做到：排障，不追责

先肯定他如实说出来、还愿意继续，再说"没做到是数据，不是失败"，然后从三个方向找原因（能力、机会、动机）：

| 卡在哪 | 听起来像 | 试试 |
|---|---|---|
| 能力 | "不知道怎么做""太累了" | 缩小动作；换一个更容易的版本；教一个具体技巧 |
| 机会 | "没时间""家里没人支持""出差" | 换时间点或提示；把环境改一改（限盐勺放在灶台边）；把特殊日子从计划里拿掉 |
| 动机 | "觉得没什么用""忘了为什么要做" | 回到他的画面和他自己说过的理由；看看这件事和目标的连接是不是太远，换一件更近的 |

排障后调整承诺：`commit set <m> C1 --action "..." --when "..." --note "原因"`。连续几周都做不到，就问他要不要暂停（`--status paused`），而不是硬撑。

## 正反馈：让做到的事被看见

正反馈是提升依从性的主要杠杆。做完一件事后马上感到"我做到了"，这种感觉会把行为和提示连得更牢（Tiny Habits 里叫"庆祝"）。所以要经常、及时、具体地肯定，规则见 [../persona.md](../persona.md)「正反馈」。

- **复盘一记录就肯定**：`commit check` 的输出里有 `celebrate`，是从记录里算出的真实事实：按约定来复盘、累计里程碑（第 1、3、5、10、20、30、50……次）、执行率创新高、中断后重新开始、部分做到、坚持了几周。挑一两条用自己的话说出来。
- **开场先说进步**：`brief` 的 `wins` 汇总了上次以来的进步：每个承诺做了几次、跨过的里程碑、记录了几次测量、结束的实验和记下的小胜利。用其中最具体的一件开场。
- **用累计，不用连胜**：累计次数永不清零，断一天也不会前功尽弃，用户不会因为一次没做到就全盘放弃。
- **夸行动，再连回目标**："连续三周每周游两次，离爬泰山又近了一点！"
- **没做到也有可肯定的**：如实说没做到、按时来复盘、主动想办法，这些都值得肯定。先肯定，再排障。

## 做到了：毕业
- 执行率连续四周以上不低于 80%（`due` 会提示 `graduate`），问他要不要"毕业"：`commit set <m> C1 --status graduated`。毕业的习惯不再每周追问，偶尔问一句"还在做吗"。
- 承诺都稳定后，问要不要把聊天节奏放慢：`profile <m> --cadence-days 30 --source "..."`。

## 复发

- 预先说好："总有一些周会掉，比如出差、生病、过年。掉了不代表白做了。"
- 掉了以后，从更小的版本重新开始，不翻旧账。
- 识别高风险情境（应酬、假期、加班季），提前一起想好"那一周的最低版本"。
