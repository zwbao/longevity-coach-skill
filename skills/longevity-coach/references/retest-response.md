# 复测有没有真动（变化相对噪声）

适用：会员问「吃了 / 做了几个月，生物年龄是不是降了」「这次复测算不算变好了」「时钟年轻了 2 岁是不是延寿了」。

不适用：能不能开始做某干预 → [intervention-advice.md](intervention-advice.md)；只问单次像多少岁 → [short-qa.md](short-qa.md)；整包复测对比仍走深度分析，但**讲法**按本文。

## 怎么做（顺序固定）

1. **先拿噪声/可判定结果**（按宿主：分析师孪生对比、`noise.py change`、或报告里的 `within_noise` / `beyond_noise`）。  
   - 在波动内 → 原样说「现在还看不出来。」不说变好、变年轻、延寿。  
   - 无噪声模型 → 两次结果只能并排看，不说真变了。
2. **若是表观遗传 / 衰老时钟类读数**，再加三道门（都过才可说「方向上有响应迹象」）：
   - **钟要靠谱**：优先用死亡风险 / 衰老速率类、技术更稳的读数（若牌照或商业模式算得出）；只有一代「历龄钟」时，**不得**单凭它宣称干预有效。  
   - **多钟同向**：同代际里至少两个可用钟同向动，且幅度不是一个乱跳、另一个不动；互相打架 → 说「信号不一致，还不能下结论」。  
   - **仍要过噪声带**：同向但都在测量/个体波动内 → 仍说「还看不出来」。
3. **固定克制句**（可加称呼，句子本身不改写成「已经延寿」）：
   - 短时时钟变化：**「短时间的时钟变化，不等于已经证明延长寿命。」**  
   - 超出噪声且同向：可以说「这次超出你的波动范围，方向是……」；**不说**「你变年轻了 N 岁所以多活 N 年」。  
   - 会员报告里的「像多少岁」仍以固定特征公式/工作流读数为准，**不用**一次干预前后的时钟差去改写那个年龄。
4. **不把**外部挖掘排名、试验热图分数、考场分写进会员报告或档案。

## 和「个人实验」的关系

化验类（血压、血脂等）仍按 [coaching.md](coaching.md)「个人实验」与噪声带判断。  
时钟类在本文三道门之上，再套同一套「超出波动才庆祝、波动内肯定行动」的态度。
