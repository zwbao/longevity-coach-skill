# 干预建议（先鉴别再谈抗衰）

适用：会员问「能不能做 / 要不要上」某项长寿相关干预——热量限制（CR）、间歇禁食（IF）、HIIT / 高强度训练、雷帕霉素、亚精胺、非瑟酮等补剂或实验性药。

不适用：只问像多少岁 / 谁更年长 / 能活多久 → [短问答](short-qa.md)；要整套报告 → 深度分析；「某某有没有用」的文献概率 → 证据库路径。

## 怎么做（顺序固定）

1. **扫安全**（对内调用分析师，不对会员念工具名）：
   ```bash
   python3 <analyst skill>/scripts/la.py method-gate safety-scan --text '<会员叙述 + 已有标志物>'
   ```
   或已有明确禁忌时：`method-gate safety --flags-json '…'`。
2. **有硬 flag**（`recommendation_bias: "no"` / `longevity_first_line: false`）：
   - 先说鉴别与就医优先，不把抗衰干预当一线。
   - 典型硬 flag：疑似库欣簇、激素紊乱鉴别、缺铁却要上限制性饮食/禁食、心梗或支架后无人监护的 HIIT、雷帕霉素剂量远高于文献常用周剂量。
   - 可整理「问医生的单子」；不进入小承诺。
3. **无硬 flag（过门后固定说法）**：
   - **先生活方式**：饮食质量（少超加工、够蛋白/纤维）、能坚持的有氧+力量、睡眠；能监督的运动优先于自己上 HIIT。
   - **再谈补剂 / 实验性药**：若有软 flag `experimental_longevity_drug`（雷帕、亚精胺、非瑟酮等），固定说清三句——(1) 这是实验性/证据有限；(2) **不给个人处方剂量当医嘱**；(3) 要动药或大剂量进「问医生的单子」。
   - **CR / IF**：过门后可以谈，仍要交代何时停（头晕、情绪/进食失控、化验变差）和复查点。
4. **对内结构**（自检时）：需要结构化时可用分析师建议字段 + `protocol-check --kind jarchow`；**不要**把五维分数或考场分写进会员报告。
5. 对人说话：用「先查清再谈抗衰」的人话；不提考场、flag 名。

## 和短问答 / 深度分析的边界

| 问法 | 走哪 |
| --- | --- |
| 能不能间歇禁食 / CR / HIIT / 雷帕 | **本文** |
| 贴了化验问像多少岁 | 短问答 |
| 交文件夹要整套方案 | 深度分析；方案里医生执行项仍不进小承诺 |
