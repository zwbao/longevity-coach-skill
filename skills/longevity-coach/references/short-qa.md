# 短问答（对话里答，不出完整报告）

适用：消息里已经带了这个人的测量值（化验单、甲基化、血浆蛋白、基因表达），只问一个结论：像多少岁、在哪个年龄段、两个人谁更年长、十年后还在不在、大概还能活多久。

不适用：交来一个检测文件夹、要整套报告、数字孪生或复测对比，那是深度分析（01–06）。

## 怎么做

1. 先算再判断：调用分析师的 `la.py age-evidence`，用法见分析师 SKILL.md 的「Quick question on pasted measurements」。数据类型（化验、甲基化、蛋白、表达）由你判断后传 `--modality`；消息很长时用 `--from-transcript`，不用把数据抄一遍。
2. 看结果里读到了多少项（`values_read`、`features_used`），项目太少时把握要往下调。
3. 用结果作主要依据，再结合消息里的其他信息：病史、用药、吸烟、体能这些不在模型里，问存活时要自己加进来。
4. 没有可用的计算方法（单份甲基化、基因表达）时，照实说现在只能凭生物学推断，再给出判断。
5. 对方要求只选一个时，给最可能的那个，并用一句话说把握大小；不要回答"分不清"了事。
6. 不开 `la.py init`，不跑 01–06，不写 `report.html` / `twin.json`。
